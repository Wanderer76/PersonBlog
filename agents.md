# Общие правила проекта

## Формат файлов

- Использовать UTF-8.
- Использовать CRLF для завершения строк.

## Обработка ошибок

- Для ожидаемых бизнес-ошибок использовать `Result<>` из
  `Common/Shared/Utils/Result.cs`.
- Не использовать исключения для управления обычным бизнес-потоком.
- Исключения допустимы для неожиданных ошибок, нарушения инвариантов
  и инфраструктурных сбоев, если они не могут быть корректно обработаны
  на текущем уровне.

## Авторизация

- Для авторизации контроллеров и endpoint'ов использовать
  `AuthFilterAttribute` вместо `AuthorizeAttribute`.

## Текущий пользователь

- Для получения данных текущего пользователя использовать
  `ICurrentUserService`.
- Не извлекать данные пользователя напрямую из `HttpContext`,
  claims или вручную через HTTP-вызовы, если необходимые данные
  доступны через `ICurrentUserService`.

## Зависимости между сборками

- `Common/Shared.csproj` разрешено использовать во всех слоях.
- `Common/Infrastructure.csproj` разрешено использовать только там,
  где это не создает нежелательную зависимость Domain/Application
  от инфраструктурных деталей.
